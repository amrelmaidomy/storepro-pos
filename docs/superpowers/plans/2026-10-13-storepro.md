# StorePro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** تسليم كود برنامج كاشير محلي بالوظائف المحددة في التصميم، واختبارات ودليل تشغيل وحزمة ZIP.

**Architecture:** واجهة CustomTkinter تستدعي خدمات أعمال منفصلة؛ SQLite محلية بمعاملات ذرية ومخطط مرقم. لا تعتمد العمليات اليومية على الإنترنت. قاعدة البيانات في مجلد بيانات المستخدم.

**Tech Stack:** Python 3.11+، SQLite، CustomTkinter، reportlab، openpyxl، arabic-reshaper، python-bidi، pytest، PyInstaller.

**Spec:** ../specs/2026-10-13-storepro-design.md

## Global Constraints
- جهاز Windows واحد؛ التشغيل بالكامل دون إنترنت.
- الأموال بوحدات صحيحة صغيرة؛ الكميات بألف جزء من الوحدة.
- لا كلمة مرور افتراضية ثابتة؛ حساب مدير عند أول تشغيل.
- قاعدة البيانات والإعدادات خارج مجلد التثبيت؛ نسخة احتياطية قبل الترحيل والاستعادة.
- المحافظة على ZIP الأصلي؛ التنفيذ في /workspace/storepro مستقل عن depi.
- الفروع والفاتورة الإلكترونية والتشغيلات ليست ضمن النسخة المحلية المحددة في التصميم.

## Review Focus
- إعادة الضغط على حفظ: معرف طلب فريد يمنع تكرار البيع والاستلام.
- باركود فارغ أو عربي: الفارغ اختياري، والبحث يدعم Unicode.
- مبلغ أكثر من منزلتين أو NaN: رفضه قبل تغيير قاعدة البيانات.
- استعادة ملف غير صحيح: رفض الملف والمحافظة على قاعدة البيانات الحالية.
- تغيير صلاحية أثناء جلسة مفتوحة: إعادة التحقق في خدمة العملية.
